ACBX AFK

Go to 'https://drive.google.com/file/d/1lUyQavCkKz6no3IkkBuV6Gy0_gXmDOIf/view?usp=drive_link' to download the zip file!
Extract it wherever you would like it.

1. Open 'AntiAFK-RBX.exe', skip the intro, and click Import.
2. Navigate to the folder ACBX_AFK and select 'AntiAFK-RBX-settings.json'.
3. Open ACBX_AFK while your ROBLOX is NOT in fullscreen, and enter your selected floor to start using potions*.
4. Select all potions you would like to be used during the AFK session.
5. BETA - Enter your email for email updates regarding Infinite progress.
6. Find a dark or single colored wall to place your 'CURRENT FLOOR: X text against'. - See 'Example_Current_Floors_Background.png' for an example of this.
7. Click 'START'.
8. AFK and enjoy!

* - Potions will only be used every 180 seconds while your infinite has not ended to conserve them as long as possible.
